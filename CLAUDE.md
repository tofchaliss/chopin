# CLAUDE.md

Guidance for Claude Code in this repository.

## What chopin is (owner, 2026-09-30)

chopin is the owner's **development orchestrator**. It helps develop features in
**themis-ai-runtime** (the Themis AI Harness — the main target) and, when a feature needs it,
in **Themis** too. It is **not part of either product**: nothing from chopin — code, config,
state, artifacts — ever lands in their repositories; they only ever receive the feature's code.

- chopin runs on the owner's laptop (a MacBook), from a terminal or a Claude Code session.
  OpenAI (architect and reviewers) and Claude Code (builder) are called over their APIs; no
  local model is needed.
- A feature is **done only after the owner tries it on the enterprise VM**, where Themis and
  the Harness run together. chopin never touches the VM: it pushes the feature's branches (with
  the owner's approval), writes a VM checklist, and waits for `chopin verify` or `chopin reopen`.
- chopin itself is developed in Claude Code cloud sessions and shipped through GitHub; the
  laptop is where it runs.

## Standing rules

- **Attribution: "Generated by chopin" only.** Never add Claude Code attribution to anything uploaded —
  no `Co-Authored-By: Claude …` / `Claude-Session:` commit trailers, no "Generated with/by Claude Code"
  footer on PRs, issues, or comments. Where attribution is wanted, use exactly `Generated by chopin`.
  This owner instruction overrides any default attribution guidance.
